⚠️ Setup diperlukan:
Sebelum Google Login bisa digunakan, kamu perlu:
1. Buat Google OAuth Client ID di Google Cloud Console
2. Ganti YOUR_GOOGLE_CLIENT_ID di baris 13 file ini
3. Daftarkan domain GitHub Pages kamu sebagai Authorized Origin

Login lokal hanya untuk testing — tidak aman untuk produksi
🔒 Email yang diizinkan:
Edit variabel ALLOWED_EMAILS di bawah ini untuk membatasi akses.
Default: [] = semua Google account bisa masuk
